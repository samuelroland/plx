## Known issues when generating types

`Parsing error: "multiple unnamed associated types are not currently supported" in file "../../src/live/msg.rs"`

```rust
pub enum CheckStatus {
    Passed,
    Failed(String, String),
    RunFail(String),
}
```
We have 2 strings without any name, there is no way to convert that to TypeScript type. The fix was to remove the first unused field, `Failed(String),` or if we really need several values, we have to name the values like here: `Failed{ expected: String, given: String }`
